Who is the customer?

Everything Cartio stores is scoped to one customer: data, collectors and credentials never cross between customers.

Compliance requirements
Used to suggest the right data mode. Shown on the customer list.

Where does their network data live?

This is set when the customer is created. Changing it later is an audited admin action: data is exported and checksums are confirmed before anything is deleted.

{{compText}} customers often require data to stay on their network. Confirm with them before choosing Hosted.
On-site store
Live view through the controller Lets engineers see this customer’s data from the controller. It passes through in memory and is never stored there. Choose explicitly: there is no default.

Sites and where discovery starts

A site is an office, a data center or a cloud region. Seed hints are IP addresses, networks no wider than /16 (IPv4) or /48 (IPv6), or host names.
